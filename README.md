# FractalMesh UI Kit

A single-file, zero-dependency dark-ops dashboard template. Drop it on any static host, point `API` at your backend's `/api/stats`, done. No npm. No build step. Works from a phone.

![og](https://samhiotisiddn-jpg.github.io/ironvision-store/og.png)

## Features
- Live stats polling with online/offline status dot
- Animated particle canvas (vanilla, ~20 lines)
- Mobile-first responsive grid
- One file. Copy, edit `const API=''`, ship.

## Use
```html
const API='http://localhost:7784'; // any endpoint returning {up, clicks:{...}}
```
